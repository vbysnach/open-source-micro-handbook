# Open Source Micro Handbook

Небольшой русскоязычный справочник по Git, GitHub, Markdown и командной работе. Он создан как практическая серия из **50 независимых документационных вкладов**: каждая карточка превращается из черновика в полезную мини-памятку.

## Цель серии

Участник `bySnach` может выполнить ровно 50 простых, осмысленных вкладов без программирования, внешних сервисов и зависимостей:

- одна карточка → одна ветка → один Pull Request → один содержательный `docs:` commit;
- один PR меняет только назначенный файл `cards/<раздел>/<номер>-<тема>.md`;
- в описании PR должна быть строка `Closes #<номер Issue>`;
- maintainer `vbysnach` проверяет и сливает PR через **Rebase and merge**.

Каждая карточка уже содержит закрытый HTML-комментарием опорный материал. Его достаточно перенести в четыре раздела, заменить статус `черновик` на `готово` и удалить комментарий. Это делает задания быстрыми, но конечный результат остаётся полезной библиотекой готовых памяток.

## Быстрый старт участника

1. Сделайте fork этого репозитория в аккаунт `bySnach`.
2. Выберите одну открытую Issue с меткой `micro-task`.
3. Создайте ветку, например `docs/doc-01-clone`.
4. Измените только файл, указанный в Issue.
5. Создайте ровно один commit вида `docs: DOC-01 complete clone card`.
6. При желании проверьте карточку: `python scripts/validate_card.py <путь-к-файлу>`.
7. Откройте PR с `Closes #<номер Issue>` и дождитесь ревью.

GitHub Actions здесь намеренно не используются: fork-PR не будет ждать `Approve and run` или других внешних проверок. Готовность проверяется по небольшому diff и структуре карточки.

## Структура

- [Карты задач](docs/task-cards.md) — все 50 независимых тем и пути файлов.
- [Правила вклада](CONTRIBUTING.md) — обязательная форма одного PR.
- [Полный контекст для участника](docs/participant-prompt-ru.md) — готовый текст задания.
- `cards/` — сами черновики будущего справочника.
- `scripts/validate_card.py` — необязательная локальная проверка одной завершённой карточки.
