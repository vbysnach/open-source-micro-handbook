# Задание участнику: 50 лёгких GitHub-вкладов

В репозитории **Open Source Micro Handbook** нужно выполнить все 50 независимых документационных задач. Это не олимпиадное программирование: каждая задача — завершить одну маленькую Markdown-карточку, используя уже подготовленный опорный материал внутри файла.

## Требуемый результат

- **50 Pull Request** из вашего fork в upstream;
- **50 содержательных commits**: ровно один `docs: DOC-XX ...` commit на каждую карточку;
- один PR закрывает одну отдельную Issue строкой `Closes #<номер>`;
- каждый PR меняет только назначенный файл `cards/.../NN-...md`;
- maintainer `vbysnach` сможет сразу проверить и слить готовый PR через Rebase and merge.

## Для каждой Issue

1. Сделайте отдельную ветку: `docs/doc-XX-<slug>`.
2. Откройте назначенную карточку и замените статус **черновик** на **готово**.
3. Заполните четыре раздела по подсказке в HTML-комментарии: «Короткий ответ», «Шаги», «Частая ошибка», «Мини-пример».
4. Удалите опорный HTML-комментарий и все строки-заполнители.
5. Проверьте карточку командой `python scripts/validate_card.py <путь>`.
6. Создайте один commit и один PR с шаблоном из репозитория.

Можно выполнять задачи подряд, не дожидаясь merge предыдущих: все 50 карточек находятся в разных файлах и не конфликтуют. В репозитории нет обязательных GitHub Actions, поэтому у fork-PR не будет внешнего блокера `Approve and run`.
