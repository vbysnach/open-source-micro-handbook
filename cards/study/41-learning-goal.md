# Небольшая учебная цель

> Карточка DOC-41 · Статус: **готово**

## Короткий ответ
Учебная цель должна быть конкретной, небольшой и проверяемой в короткий срок.

## Шаги
- Начните с действия, которое можно выполнить.
- Ограничьте цель одной темой.
- Назовите признак завершения.

## Частая ошибка
Ставить цель «изучить всё» без срока и результата.

## Мини-пример
```text
Цель: до пятницы открыть один docs PR с понятным описанием.
```
