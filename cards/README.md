# Карточки справочника

Каждая папка содержит независимые черновики. Вклад в одну карточку не должен затрагивать этот файл или соседние карточки.

Статус `черновик` означает, что для карточки открыта Issue. Статус `готово` означает, что участник заполнил все разделы, удалил опорный комментарий, а PR был слит.
