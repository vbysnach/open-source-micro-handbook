# Короткий запрос ревью

> Карточка DOC-15 · Статус: **готово**

## Короткий ответ
Запрос на ревью должен назвать задачу, scope и желаемый фокус проверки.

## Шаги
- Укажите ссылку или номер PR.
- Напомните ID завершённой карточки.
- Спросите о конкретном аспекте, если он вызывает сомнение.

## Частая ошибка
Отправлять ревьюеру длинное сообщение без ссылки на PR или цели.

## Мини-пример
```text
Пожалуйста, проверьте DOC-15: изменён только один файл и пример понятен новичку.
```
