# Когда использовать Draft PR

> Карточка DOC-14 · Статус: **готово**

## Короткий ответ
Draft PR подходит для раннего обсуждения, когда работа ещё не готова к слиянию.

## Шаги
- Откройте Draft PR, если хотите получить раннюю обратную связь.
- Снимите Draft только после завершения карточки.
- Не просите merge, пока обязательные разделы не заполнены.

## Частая ошибка
Создавать обычный готовый PR, если работа содержит явные незавершённые части.

## Мини-пример
```text
Draft: требуется проверить формулировку примера.
```
