# Маленькие ветки и маленькие PR

> Карточка DOC-17 · Статус: **готово**

## Короткий ответ
Одна ветка и один PR на одну задачу уменьшают конфликты и упрощают ревью.

## Шаги
- Выберите одну открытую Issue.
- Измените только её назначенную карточку.
- Откройте PR сразу после одной завершённой задачи.

## Частая ошибка
Добавлять в текущую ветку следующую задачу, пока предыдущая ещё на ревью.

## Мини-пример
```text
ветка docs/doc-17-small-branches → один файл → один PR
```
