# Краткое описание Pull Request

> Карточка DOC-13 · Статус: **готово**

## Короткий ответ
Описание PR объясняет, какую одну задачу решает изменение и как его проверить.

## Шаги
- Укажите ID карточки и её цель.
- Напишите, какой файл изменён.
- Добавьте краткое доказательство: просмотр Markdown или запуск проверки.

## Частая ошибка
Оставлять PR без контекста, заставляя ревьюера угадывать цель.

## Мини-пример
```text
## Что сделано
Завершена DOC-13.

## Проверка
Открыта и прочитана карточка.
```
