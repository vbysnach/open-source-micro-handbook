# Связь PR и Issue

> Карточка DOC-12 · Статус: **готово**

## Короткий ответ
Фраза `Closes #<номер>` в описании PR связывает работу с Issue и закрывает её после merge.

## Шаги
- Найдите номер назначенной Issue.
- Добавьте отдельной строкой `Closes #<номер>` в описание PR.
- Проверьте, что GitHub показал связанную Issue.

## Частая ошибка
Писать номер без ключевого слова и ожидать автоматического закрытия.

## Мини-пример
```text
Closes #12
```
