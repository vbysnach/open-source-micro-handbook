# Различие способов merge

> Карточка DOC-19 · Статус: **готово**

## Короткий ответ
Merge commit сохраняет ветку, squash объединяет коммиты, а rebase переносит коммиты в линейную историю.

## Шаги
- Используйте merge commit, когда важна форма ветки.
- Используйте squash для нескольких мелких коммитов одной задачи.
- Используйте rebase для линейной серии одного commit на PR.

## Частая ошибка
Считать, что все способы merge сохраняют историю одинаково.

## Мини-пример
```text
merge: сохраняет ветку
squash: объединяет commits
rebase: переносит commits линейно
```
