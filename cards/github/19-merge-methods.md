Короткий ответ: Merge commit сохраняет ветку, squash объединяет коммиты, а rebase переносит коммиты в линейную историю.

Шаги:
1. Используйте merge commit, когда важна форма ветки.
2. Используйте squash для нескольких мелких коммитов одной задачи.
3. Используйте rebase для линейной серии одного commit на PR.

Частая ошибка: Считать, что все способы merge сохраняют историю одинаково.

merge: сохраняет ветку
squash: объединяет commits
rebase: переносит commits линейно
