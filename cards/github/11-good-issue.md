# Понятная GitHub Issue

> Карточка DOC-11 · Статус: **готово**

## Короткий ответ
Хорошая Issue описывает проблему, ожидаемый результат и границы одной небольшой задачи.

## Шаги
- Дайте Issue конкретный заголовок.
- Опишите, что должно получиться после работы.
- Укажите один файл или один небольшой участок задачи.

## Частая ошибка
Оставлять Issue с одним словом без ожидаемого результата.

## Мини-пример
```text
Заголовок: DOC-11: уточнить шаблон Issue
Ожидаемый результат: шаблон содержит цель и критерий готовности.
```
