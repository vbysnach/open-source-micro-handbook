# Короткая заметка к релизу

> Карточка DOC-20 · Статус: **готово**

## Короткий ответ
Release note сообщает пользователю самый заметный результат без внутренней технической детали.

## Шаги
- Назовите версию или дату.
- Перечислите одно-два видимых изменения.
- Укажите важное действие пользователя, если оно нужно.

## Частая ошибка
Копировать в заметку весь журнал коммитов.

## Мини-пример
```text
## 0.1.0
- Добавлены первые готовые карточки справочника.
```
