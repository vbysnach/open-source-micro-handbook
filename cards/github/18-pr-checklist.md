# Чек-лист готовности PR

> Карточка DOC-18 · Статус: **готово**

## Короткий ответ
Короткий чек-лист снижает риск отправить незавершённую или лишнюю правку.

## Шаги
- Проверьте один изменённый файл.
- Проверьте один содержательный commit.
- Добавьте `Closes #<номер>` и понятное описание.

## Частая ошибка
Считать PR готовым только потому, что кнопка Create pull request доступна.

## Мини-пример
```text
- [x] Один файл
- [x] Один commit
- [x] Issue связана
```
