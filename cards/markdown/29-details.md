# Сворачиваемый блок details

> Карточка DOC-29 · Статус: **готово**

## Короткий ответ
Тег `<details>` прячет вспомогательные подробности, сохраняя основной текст коротким.

## Шаги
- Добавьте `<summary>` с понятной подписью.
- Поместите внутрь необязательную справку.
- Проверьте, что ключевой смысл виден без раскрытия блока.

## Частая ошибка
Скрывать внутри details обязательную инструкцию, без которой нельзя начать работу.

## Мини-пример
```text
<details>
<summary>Показать пример</summary>

`git status`
</details>
```
