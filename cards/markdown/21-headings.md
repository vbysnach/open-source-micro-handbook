# Иерархия Markdown-заголовков

> Карточка DOC-21 · Статус: **готово**

## Короткий ответ
Заголовки Markdown должны идти последовательно: один H1, затем логичные H2 и H3.

## Шаги
- Начните документ с одного `#` заголовка.
- Разделы оформляйте через `##`.
- Не перескакивайте с H1 сразу на H4.

## Частая ошибка
Использовать несколько главных заголовков `#` в одной маленькой странице.

## Мини-пример
```text
# Руководство

## Установка

### Windows
```
