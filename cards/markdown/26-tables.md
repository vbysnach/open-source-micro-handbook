# Небольшая таблица Markdown

> Карточка DOC-26 · Статус: **готово**

## Короткий ответ
Таблица удобна для сравнения одинаковых полей, но не заменяет текст для сложного объяснения.

## Шаги
- Начните с строки заголовков.
- Добавьте строку разделителей из дефисов.
- Держите в ячейках короткие однотипные значения.

## Частая ошибка
Помещать в таблицу длинные абзацы или многоуровневые списки.

## Мини-пример
```text
| Команда | Назначение |
| --- | --- |
| `git status` | Состояние файлов |
```
