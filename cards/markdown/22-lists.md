# Понятные списки в Markdown

> Карточка DOC-22 · Статус: **готово**

## Короткий ответ
Маркированные списки подходят для набора пунктов, а нумерованные — для порядка действий.

## Шаги
- Используйте `-` для независимых пунктов.
- Используйте `1.` для шагов, которые выполняются по порядку.
- Делайте каждый пункт коротким и однотипным.

## Частая ошибка
Смешивать символы списка и ломать нумерацию ради оформления.

## Мини-пример
```text
1. Откройте файл
2. Внесите правку
3. Проверьте diff
```
