# Команды и блоки кода

> Карточка DOC-23 · Статус: **готово**

## Короткий ответ
Короткие команды помещают в обратные кавычки, а многострочный код — в fenced block с языком.

## Шаги
- Выделяйте одну команду через `` `команда` ``.
- Для нескольких строк используйте тройные обратные кавычки.
- Указывайте язык блока, если он известен.

## Частая ошибка
Писать команды обычным текстом, где их трудно скопировать и отличить от пояснения.

## Мини-пример
````text
```bash
git status
git diff
```
````
