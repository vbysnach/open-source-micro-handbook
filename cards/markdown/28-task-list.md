# Чек-лист задач в Markdown

> Карточка DOC-28 · Статус: **готово**

## Короткий ответ
Список задач показывает видимый прогресс по небольшому набору проверяемых действий.

## Шаги
- Используйте `- [ ]` для незавершённого пункта.
- Ставьте `- [x]` только после фактического выполнения.
- Формулируйте каждый пункт как проверяемое действие.

## Частая ошибка
Отмечать пункт выполненным до проверки результата.

## Мини-пример
```text
- [x] Проверен diff
- [ ] Открыт PR
```
