# Полезный alt-текст изображения

> Карточка DOC-25 · Статус: **готово**

## Короткий ответ
Alt-текст кратко передаёт смысл изображения тем, кто его не видит или отключил.

## Шаги
- Опишите цель изображения, а не только его тип.
- Не начинайте с фразы «картинка» или «изображение».
- Оставьте alt пустым только для чисто декоративного элемента.

## Частая ошибка
Писать alt `скриншот` без содержательного описания.

## Мини-пример
```text
![Кнопка создания новой Issue в правом верхнем углу списка задач](image.png)
```
