# Понятные текстовые ссылки

> Карточка DOC-24 · Статус: **готово**

## Короткий ответ
Текст ссылки должен объяснять, куда ведёт ссылка, без фраз вроде «нажмите здесь».

## Шаги
- Назовите объект, на который ведёт ссылка.
- Используйте Markdown-формат `[текст](URL)`.
- Проверьте, что адрес открывается и у читателя понятен смысл.

## Частая ошибка
Оставлять длинный URL посреди обычного предложения без подписи.

## Мини-пример
```text
[Руководство по Markdown](https://www.markdownguide.org/)
```
