# Чек-лист ручной проверки

> Карточка DOC-48 · Статус: **готово**

## Короткий ответ
Manual check описывает короткие шаги, которые человек может повторить без скрытых знаний.

## Шаги
- Начните с исходного состояния.
- Опишите действие пользователя.
- Назовите ожидаемый результат.

## Частая ошибка
Писать «проверить вручную», не уточняя, что именно делать.

## Мини-пример
```text
1. Открыть карточку.
2. Прочитать пример.
3. Убедиться, что команды выделены кодом.
```
