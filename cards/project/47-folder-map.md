# Описание структуры папок

> Карточка DOC-47 · Статус: **готово**

## Короткий ответ
Карта папок в README помогает быстро найти код, документацию и проверки.

## Шаги
- Перечислите только ключевые папки.
- Добавьте короткое назначение к каждой.
- Поддерживайте карту при заметной перестройке структуры.

## Частая ошибка
Публиковать полный технический дамп дерева из сотен файлов.

## Мини-пример
```text
- `cards/` — карточки справочника
- `docs/` — инструкции
- `scripts/` — локальная проверка
```
