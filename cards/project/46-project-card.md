# Карточка малого проекта

> Карточка DOC-46 · Статус: **готово**

## Короткий ответ
Project card кратко фиксирует цель, способ запуска и видимый результат маленького проекта.

## Шаги
- Сформулируйте цель в одном предложении.
- Укажите минимальный способ запуска или просмотра.
- Опишите ожидаемый результат.

## Частая ошибка
Описывать проект только красивыми словами без проверяемого результата.

## Мини-пример
```text
Цель: справочник для новичков.
Запуск: открыть README.
Результат: видны 50 карточек.
```
