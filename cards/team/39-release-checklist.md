# Чек-лист малого релиза

> Карточка DOC-39 · Статус: **готово**

## Короткий ответ
Небольшой release checklist подтверждает, что версия понятна, проверена и сопровождается заметкой.

## Шаги
- Проверьте выбранные изменения.
- Обновите короткую release note.
- Назовите версию или дату публикации.

## Частая ошибка
Считать релиз готовым без проверки списка изменений.

## Мини-пример
```text
- [ ] Изменения проверены
- [ ] Release note готова
- [ ] Версия указана
```
