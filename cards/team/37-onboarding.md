# Чек-лист первого дня

> Карточка DOC-37 · Статус: **готово**

## Короткий ответ
Чек-лист онбординга помогает новичку получить доступы, понять цель и сделать безопасный первый вклад.

## Шаги
- Дайте ссылку на основной README.
- Укажите безопасную первую задачу.
- Добавьте способ задать вопрос или получить ревью.

## Частая ошибка
Сразу назначать новичку большую задачу без ориентира.

## Мини-пример
```text
- [ ] Прочитан README
- [ ] Выбрана добрая первая задача
- [ ] Найден ревьюер
```
