# Понятное сообщение коммита

> Карточка DOC-05 · Статус: **готово**

## Короткий ответ
Хороший commit message коротко описывает одно законченное изменение в повелительном стиле.

## Шаги
- Начните сообщение с типа изменения, например `docs:`.
- Назовите конкретную карточку или тему.
- Не объединяйте в сообщении несколько несвязанных действий.

## Частая ошибка
Писать сообщения вроде `update`, из которых непонятно, что изменилось.

## Мини-пример
```text
docs: DOC-05 add commit message guidance
```
