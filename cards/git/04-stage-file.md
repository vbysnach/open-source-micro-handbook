# Добавление одного файла в staging

> Карточка DOC-04 · Статус: **готово**

## Короткий ответ
`git add <путь>` готовит выбранный файл к следующему коммиту.

## Шаги
- Проверьте изменение через `git diff`.
- Добавьте точный путь командой `git add <путь>`.
- Проверьте staged-версию через `git diff --staged`.

## Частая ошибка
Использовать `git add .`, не убедившись, что в папке нет лишних файлов.

## Мини-пример
```text
git add cards/git/04-stage-file.md
```
