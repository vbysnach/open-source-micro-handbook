# Проверка diff перед коммитом

> Карточка DOC-06 · Статус: **готово**

## Короткий ответ
`git diff` помогает увидеть фактическое изменение до того, как оно попадёт в историю.

## Шаги
- Проверьте обычный diff до `git add`.
- После staging проверьте `git diff --staged`.
- Убедитесь, что меняется только файл назначенной карточки.

## Частая ошибка
Коммитить текст с случайной правкой соседнего файла.

## Мини-пример
```text
git diff --staged -- cards/git/06-diff.md
```
