# Просмотр недавней истории

> Карточка DOC-09 · Статус: **готово**

## Короткий ответ
`git log --oneline` показывает короткую историю коммитов и помогает проверить порядок изменений.

## Шаги
- Запустите `git log --oneline -n 10`.
- Найдите свой последний commit subject.
- При необходимости сравните ветку с `origin/main`.

## Частая ошибка
Путать историю текущей ветки с историей удалённого main.

## Мини-пример
```text
git log --oneline -n 10
```
