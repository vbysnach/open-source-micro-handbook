# Проверка состояния рабочего дерева

> Карточка DOC-02 · Статус: **готово**

## Короткий ответ
`git status` показывает изменённые, подготовленные и неотслеживаемые файлы.

## Шаги
- Запустите `git status` перед началом работы.
- Прочитайте секции Changes, Staged и Untracked.
- Убедитесь, что в коммит попадут только нужные файлы.

## Частая ошибка
Делать коммит, не проверив, какие изменения уже лежат в staging.

## Мини-пример
```text
git status
```
