# Разрешение текстового конфликта

> Карточка DOC-08 · Статус: **готово**

## Короткий ответ
Конфликт решается вручную: выбирается корректный текст, маркеры удаляются, затем продолжается rebase.

## Шаги
- Откройте файл с маркерами `<<<<<<<`, `=======`, `>>>>>>>`.
- Оставьте согласованный вариант текста и удалите все маркеры.
- Добавьте файл и выполните `git rebase --continue`.

## Частая ошибка
Оставить конфликтные маркеры в документе или угадывать, не читая оба варианта.

## Мини-пример
```text
git add cards/git/08-text-conflict.md && git rebase --continue
```
