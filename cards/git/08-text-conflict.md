Короткий ответ: Конфликт решается вручную: выбирается корректный текст, маркеры удаляются, затем продолжается rebase.

Шаги:
1. Откройте файл с маркерами `<<<<<<<`, `=======`, `>>>>>>>`.
2. Оставьте согласованный вариант текста и удалите все маркеры.
3. Добавьте файл и выполните `git rebase --continue`.

Частая ошибка: Оставить конфликтные маркеры в документе или угадывать, не читая оба варианта.

Мини-пример:
git add cards/git/08-text-conflict.md && git rebase --continue
