# Отдельная ветка для одной задачи

> Карточка DOC-03 · Статус: **готово**

## Короткий ответ
Новая ветка изолирует одну задачу и делает будущий PR понятным.

## Шаги
- Обновите локальную ветку `main`.
- Создайте ветку с осмысленным именем задачи.
- Работайте в ней до открытия одного PR.

## Частая ошибка
Смешивать несколько несвязанных задач в одной ветке.

## Мини-пример
```text
git switch -c docs/doc-03-branch
```
