Короткий ответ: Rebase переносит ваши локальные коммиты поверх актуальной базовой ветки и сохраняет линейную историю.

Шаги:
1. Сохраните незакоммиченные изменения.
2. Получите свежие данные командой `git fetch origin`.
3. В своей ветке выполните `git rebase origin/main` и проверьте результат.

Частая ошибка: Выполнять rebase с незавершёнными конфликтами или терять изменения командой reset.

Мини-пример:
git fetch origin && git rebase origin/main
