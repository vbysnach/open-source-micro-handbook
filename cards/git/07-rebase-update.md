# Обновление ветки через rebase

> Карточка DOC-07 · Статус: **готово**

## Короткий ответ
Rebase переносит ваши локальные коммиты поверх актуальной базовой ветки и сохраняет линейную историю.

## Шаги
- Сохраните незакоммиченные изменения.
- Получите свежие данные командой `git fetch origin`.
- В своей ветке выполните `git rebase origin/main` и проверьте результат.

## Частая ошибка
Выполнять rebase с незавершёнными конфликтами или терять изменения командой reset.

## Мини-пример
```text
git fetch origin && git rebase origin/main
```
