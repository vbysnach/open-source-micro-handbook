# Клонирование репозитория

> Карточка DOC-01 · Статус: **готово**

## Короткий ответ
Команда `git clone <URL>` создаёт локальную копию удалённого репозитория.

## Шаги
- Откройте страницу репозитория и скопируйте HTTPS-адрес.
- В терминале выполните `git clone <URL>`.
- Перейдите в созданную папку командой `cd <имя-папки>`.

## Частая ошибка
Клонировать репозиторий в уже занятую папку и затем работать не из той директории.

## Мини-пример
```text
git clone https://github.com/example/project.git
```
