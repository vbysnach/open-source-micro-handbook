# Вклад в Micro Handbook

Это серия очень маленьких, самостоятельных документационных задач. Не нужно писать программу, устанавливать пакеты или искать информацию во внешних источниках: в каждой карточке есть опорный материал.

## Строгая форма одного вклада

1. Выберите одну открытую Issue `DOC-XX`.
2. Создайте отдельную ветку от свежей `main`.
3. Измените **только** файл карточки, указанный в Issue.
4. В карточке:
   - поменяйте статус **черновик** на **готово**;
   - заполните разделы «Короткий ответ», «Шаги», «Частая ошибка» и «Мини-пример»;
   - удалите HTML-комментарий «Опорный материал» и все строки-заполнители.
5. Создайте ровно один осмысленный commit: `docs: DOC-XX <краткое действие>`.
6. Откройте один PR и добавьте в описание `Closes #<номер Issue>`.

Не меняйте README, индекс карточек, шаблоны GitHub или другие карточки в том же PR. Это исключает конфликты между 50 параллельными ветками.

## Проверка перед PR

Команда ниже необязательна, но должна завершиться сообщением `OK` для готовой карточки:

```bash
python scripts/validate_card.py cards/git/01-clone.md
```

В репозитории нет обязательного CI, поэтому fork-PR не получат статус `action_required`. Maintainer проверяет маленький diff, одобряет PR и применяет **Rebase and merge**.

## Что считается хорошим вкладом

- Изменён ровно один назначенный файл.
- Текст понятен начинающему и соответствует опорному материалу.
- История PR содержит ровно один тематический `docs:` commit.
- Description содержит ссылку на Issue через `Closes #...`.
